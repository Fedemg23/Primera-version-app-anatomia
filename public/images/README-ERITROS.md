# Imagen de Eritros

## Archivo requerido
Se necesita agregar una imagen PNG llamada `eritros.png` en esta carpeta (`public/images/`).

## Especificaciones
- **Nombre del archivo:** `eritros.png`
- **Formato:** PNG con transparencia (alpha channel)
- **Tamaño recomendado:** 128x128 px o 256x256 px
- **Contenido:** Imagen de un glóbulo rojo / eritrocito (debe ser circular y rojo)

## Uso
Esta imagen se utiliza para representar los **Eritros**, que es la moneda/puntos de rating del modo Ranked.

Se muestra en:
- Pantalla principal de Ranked (rating del jugador)
- Resumen de partidas (cambios de rating)
- Clasificación/Leaderboard
- Progreso de temporada

## Fallback
Si la imagen no existe, el sistema mostrará automáticamente un emoji 🔴 como respaldo.

## Ejemplo de cómo debería verse
La imagen debe representar un glóbulo rojo (eritrocito) y tener un estilo consistente con el resto de las imágenes del juego. Debe ser redonda y de color rojo, similar a la apariencia de un glóbulo rojo en ilustraciones médicas.
